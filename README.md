# 🌾 SHIVAR

## **AI-Powered End-to-End Farm-to-Market Agricultural Ecosystem**

> **From What to Grow → Who to Sell → How to Deliver — SHIVAR connects the entire agricultural journey.**

**SHIVAR** is an AI-powered agricultural ecosystem built to connect **farmers, industries, bulk buyers, FPOs, logistics partners, and agricultural information services** through one integrated digital platform.

Instead of solving only one part of agriculture, SHIVAR brings together **crop planning, AI agricultural advisory, climate intelligence, market intelligence, price forecasting, demand discovery, FPO connectivity, government schemes, buyer matching, bidding, communication, and logistics coordination**.

The goal is simple:

> **Help farmers make better decisions, reach the right market, connect directly with suitable buyers, and move their produce from farm to final delivery through one connected ecosystem.**

---

# 🚨 The Problem

Indian agriculture is not only a production challenge. It is also a **market-access, information, transparency, connectivity, and supply-chain challenge**.

Farmers can face:

- Limited direct access to industries and bulk buyers
- Dependence on multiple intermediaries
- Limited price transparency and price discovery
- Uncertainty about future demand
- Difficulty deciding what and when to grow
- Weather and climate uncertainty
- Crop disease and pest-related challenges
- Difficulty finding profitable market opportunities
- Fragmented communication with buyers
- Limited awareness of relevant government schemes
- Difficulty discovering nearby FPOs and agricultural networks
- Logistics challenges after a deal is finalized

At the other end, businesses and industries face:

- Fragmented farmer networks
- Difficulty discovering suitable suppliers
- Uncertainty about crop availability and quantity
- Time-consuming sourcing
- Difficulty identifying geographically suitable farmers
- Communication and negotiation friction
- Additional logistics complexity

### The result

A farmer may produce the **right crop, at the right time, in the right quantity**, yet still struggle to reach the **right buyer at the right market opportunity**.

SHIVAR addresses this gap by connecting the **decision-making, marketplace, and supply-chain layers**.

# 💡 The SHIVAR Solution

SHIVAR creates a unified digital bridge between:

**🌾 Farmers + 🤖 AI + 🌦️ Climate + 📊 Markets + 🏭 Industries + 🤝 FPOs + 🚚 Logistics + 🏛️ Government Schemes**

# 💻 Getting Started

## Prerequisites

Make sure you have installed:

- **Node.js**
- **MongoDB Atlas account**
- **Git**
- **Modern web browser**

---

## 1. Clone the Repository

```bash
git clone <YOUR-REPOSITORY-URL>
cd SHIVAR
```

---

## 2. Install Backend Dependencies

```bash
npm install
```

---

## 3. Configure Environment Variables

Create a `.env` file in the backend directory.

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
AI_API_KEY=your_ai_api_key
WEATHER_API_KEY=your_weather_api_key
```

Additional API credentials can be configured according to the enabled intelligence and mapping services.

> **Never commit `.env` files, API keys, database credentials, or other secrets to GitHub.**

---

## 4. Start the Backend

```bash
npm start
```

For development:

```bash
npm run dev
```

---

## 5. Run the Frontend

Open the frontend using your preferred local development environment or **Live Server**.
